# Deadline Buddy

## Product Description
Deadline Buddy is a mobile application that helps university students manage assignments and deadlines in one place.

## Target Users and Problem
**Target users:** University students who have assignments from several subjects.

**Problem:** Students often receive tasks from different teachers and platforms, so they forget deadlines or do not know which task is the most urgent.

**Example situation:** A student receives three assignments on the same day and wants to quickly save them with their deadlines.

## Main Features
1. **Add task** – enter a title, subject and deadline.
2. **Task list** – tasks are sorted by the nearest deadline.
3. **Reminders** – a notification one day before the deadline.
4. **Mark as done** – completed tasks are marked and moved down the list.

## Proposed Technologies
- **Programming language / framework:** Flutter (Dart) – one codebase for Android and iOS.
- **Platform:** Mobile application (Android 8+ and iOS 14+).
- **Internet:** Not required for viewing and adding tasks; needed only for syncing data between devices.

*Reason for the choice:* Flutter is suitable for beginners and allows us to build a simple cross-platform app.

## How to Explore the Prototype
1. Open the prototype link.
2. Start from the **Task List** screen.
3. Click **"+ Add task"** and fill in the form.
4. Click **Save** to return to the list.
5. Open a task to see its details and the **Mark as done** button.
6. Open **Settings** to choose the reminder time.

*Note:* This is a clickable prototype, not a working application. Syncing and real notifications are planned features only.
